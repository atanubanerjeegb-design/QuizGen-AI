## 📖 Overview

QuizGen AI is an intelligent quiz generation platform that transforms study materials into interactive multiple-choice quizzes. Users can upload PDFs, images, or documents, and the application automatically extracts the content using OCR (when required) and generates relevant MCQs using Natural Language Processing (NLP).

The project aims to make studying more efficient by reducing the time spent creating practice questions while providing a clean, responsive, and user-friendly experience.

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/your-username/QuizGen-AI.git
```

### Navigate to the project directory

```bash
cd QuizGen-AI
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the application

```bash
uvicorn main:app --reload
```

Visit:

```
http://127.0.0.1:8000
```

## 📖 How It Works

1. Register or Login
2. Upload a PDF, Image, or Document
3. The application extracts the content
4. AI processes the extracted text
5. Multiple-choice questions are generated
6. Attempt the quiz
7. View your score and quiz history
